## 🚀 Come avviare l'applicazione in locale

Apri semplicemente il file `src/index.html` in qualsiasi browser, oppure usa un server locale:

```bash
# Con Python
python3 -m http.server 3000 --directory src

# Oppure con npx serve
npx serve src
```
